# 🚀 GUIDA RAPIDA: Abilitare GitHub Pages

## ⏱️ Tempo necessario: 3 minuti

---

## 📝 PASSI DA SEGUIRE

### 1️⃣ Vai sul Repository GitHub

Apri il browser e vai su:
```
https://github.com/RobertoPoggi/csp-novi-telecare
```

### 2️⃣ Accedi a Settings

1. Fai login con l'account GitHub **RobertoPoggi**
2. Nella pagina del repository, clicca su **Settings** (in alto a destra)

### 3️⃣ Naviga su Pages

Nel menu laterale sinistro:
1. Scorri verso il basso
2. Clicca su **Pages** (nella sezione "Code and automation")

### 4️⃣ Configura GitHub Pages

Nella sezione "Build and deployment":

1. **Source**: Seleziona **Deploy from a branch**
2. **Branch**: 
   - Seleziona **main** dal primo dropdown
   - Seleziona **/ (root)** dal secondo dropdown
3. Clicca sul pulsante **Save**

### 5️⃣ Attendi il Deploy

1. Vedrai un messaggio: "Your site is being built from the main branch"
2. Attendi **2-3 minuti**
3. Ricarica la pagina (F5)
4. Vedrai: "Your site is live at https://robertopoggi.github.io/csp-novi-telecare/"

### 6️⃣ Verifica il Sito

Clicca sul link o visita:
```
https://robertopoggi.github.io/csp-novi-telecare/
```

Dovresti vedere la **Dashboard TeleCare H24** funzionante! ✅

## ❓ PROBLEMI?

### Non vedo l'opzione "Pages" in Settings
- **Causa**: Il repository potrebbe essere privato
- **Soluzione**: Vai su Settings → Danger Zone → Change repository visibility → Public

### Il sito non carica dopo 5 minuti
- **Causa**: Cache del browser
- **Soluzione**: Premi Ctrl+Shift+R (Windows) o Cmd+Shift+R (Mac)

### Errore 404
- **Causa**: Deploy non completato
- **Soluzione**: Torna su Settings → Pages e verifica lo stato
